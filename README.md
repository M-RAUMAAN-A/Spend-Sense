# Spend-Sense


Students often make many small purchases and lose track of their total spending, their largest expense categories, and how much of their monthly allowance remains. Existing finance applications tend to be bank-connected, account-based, or opaque in how they produce advice, which makes them a poor fit for a learning environment. This paper presents SpendSense, a single-user, locally run expense analyzer built with R, Shiny, bslib, ggplot2, and dplyr, using plain CSV files as its only persistent storage. SpendSense lets a user record transactions, import and export CSV data, set overall and per-category monthly budgets, view interactive charts, and read rule-based spending insights. The system is organised into a frontend layer, a backend data-manager layer, an analytics layer, and an insights layer, connected through a simple flow of input, validation, storage, calculation, and reactive display. The project deliberately avoids SQL databases and artificial intelligence so that every number and message on screen can be traced to a short, readable piece of code. This paper describes the design, implementation, and verification status of the system, discusses its limitations, and outlines directions for future work.
